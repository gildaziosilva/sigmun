# 0001 — Adoção da licença Apache License 2.0

 Status: Aceita
 Data: 2026-08-17
 Decisor(es): Equipe SIGMUN

Contexto

O projeto SIGMUN precisa de uma licença de código-fonte clara para reger uso,
distribuição e contribuições. A escolha da licença deve equilibrar permissividade,
compatibilidade com dependências de terceiros e requisitos institucionais.

Decisão

Adotamos a Apache License, Version 2.0, como a licença oficial do projeto
SIGMUN. O arquivo `LICENSE` contendo o texto da licença foi adicionado à raiz
do repositório.

Motivos

- Licença permissiva com proteção de patentes.
- Ampla adoção e compatibilidade com muitos projetos open-source.
- Adequada para uso por órgãos públicos e colaboração externa.

Consequências

- Todos os artefatos de código do repositório serão distribuídos sob a
  Apache-2.0 a menos que indicado explicitamente em arquivos específicos.
- Contribuidores deverão aceitar que suas contribuições sejam disponibilizadas
  sob Apache-2.0 (sujeito a políticas internas descritas no guia de contribuição).

Referências

- `LICENSE` (arquivo na raiz do repositório)
- Apache License 2.0 — http://www.apache.org/licenses/LICENSE-2.0

# 2. Regras propostas

| Identificador | Descrição | Fonte |
| --- | --- | --- |
| RN-CPT-001 | lacuna é a diferença entre o nível esperado e o nível avaliado da competência. | modelo proposto |
| RN-CPT-002 | capacitação só recebe inscrição com inscrições abertas e vaga disponível. | modelo proposto |
| RN-CPT-003 | a pessoa é referenciada por identificador opaco do DOM-PES. | modelo proposto |

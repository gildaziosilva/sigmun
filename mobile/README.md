# SIGMUN Mobile

Aplicativos móveis do SIGMUN.

## Estrutura

```
mobile/
├── cidadao/              # App para cidadãos
├── fiscalizacao/         # App para fiscalização
├── saude/                # App para saúde
└── equipes-externas/     # App para equipes externas
```

## Tecnologias

- **Framework:** React Native
- **Armazenamento local:** SQLite/Realm
- **Sincronização:** Offline-first com sync posterior
- **Notificações:** Push notifications

## Funcionalidades

- Operação offline
- Sincronização posterior
- Notificações push
- Acessibilidade
